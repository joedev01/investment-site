# InvestPro

InvestPro is a modern investment dashboard frontend built with Next.js and Tailwind CSS.

## Features

- Modern landing page
- Dashboard overview
- Investment plans
- My investments
- Transaction history
- Wallet management
- User profile
- Login and registration pages
- Responsive design

## Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- Lucide React
